# WhoIsFree

**Free time. Real people. Real experiences.**

Android app (Expo SDK 58 / React Native, expo-router) to tell people nearby you are free right now and turn free time into real activities.

## Status (test build)
- Frontend: 5 tabs (Home, Radar, Create, Messages, Profile) + onboarding, auth, availability, people, chat, activities, Surprise me, Live moments, notifications, settings, safety, plans overview, admin. EN / FR / AR (RTL).
- Backend: Supabase, tables prefixed `wif_` (see `supabase/migrations`). Locations are snapped to a ~2 km grid server-side; clients only ever receive distance bands.
- Not active yet: paid plans (no RevenueCat / Play products configured, no prices shown), push notifications, AI assistant, marketplace.

## Build
Every push to `main` builds a release APK (`.github/workflows/android-apk.yml`) and publishes it as a GitHub release `build-N`.

Only publishable keys are used in the app. Never put a service-role key in the app or this repo.

## AI companions (v1.1)
- 100 fictional adult characters (50 F / 50 M) in `wif_companions`, generated by `tools/gen_companions.py` (names, jobs, personalities, speaking styles, quirks, EN/FR/AR bios, 3–5 lifestyle scenes each).
- Pictures are original illustrations drawn in code (`src/features/companions/art.ts`). An admin can set `portrait_path` to a real image later.
- Fully separate from real users: own tables, never in discover / radar / requests / activities; no location, availability or meetup data.
- Disclosure must be accepted before the first chat (`wif_companion_start`). Small "AI" badge on cards, "AI companion" in chat.
- Replies: edge function `wif-companion-chat` (service-role RPCs `wif_ai_context` / `wif_ai_save_turn` / `wif_ai_save_memory`). Needs the Supabase secret `ANTHROPIC_API_KEY` (optional `WIF_AI_MODEL`). Without it the app shows "AI replies are not switched on yet".
- Optional memory per character (summary notes, off by default), clear conversation, 80 AI messages/user/day.
- Tests: `bash tests/sql/*` on a local Postgres, `node --experimental-strip-types --test tests/companion-chat.test.mts`.
